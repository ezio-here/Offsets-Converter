Offset Converter Tool

Convert Search & Replace codes to EnzoMem offsets format

Enter hex bytes separated by spaces. Use ?? for wildcards.

Enter hex bytes with the same length as search code. 


                

            

        


        
        

            
📝 Example Usage:

            

                
Search: CD CC 4C 3F 00 00 80 3F 00 00 80 3E

                
Replace: CD CC 4C 3F 00 00 80 3A 00 00 80 3A

                
↓ Output ↓

                

                    
if (enable)

                    
{

                    
    offsets.Add(7, new byte[] { 0x3A });  // Original: 0x3F

                    
    offsets.Add(11, new byte[] { 0x3A });  // Original: 0x3E

                    
}

                    
else

                    
{

                    
    offsets.Add(7, new byte[] { 0x3F });  // Revert to: 0x3F

                    
    offsets.Add(11, new byte[] { 0x3E });  // Revert to: 0x3E

                    
}
